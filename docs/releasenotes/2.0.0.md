# v2.0.0 — rebuilt as a native app

AWS Profile Manager 2.0 is a ground-up rewrite. It does everything 1.x did, but it starts faster,
uses much less memory and is a fraction of the download. Everything you had comes with you:
profiles, folders, settings, saved sign-ins and your app icon. Nothing needs to be set up again.

2.0 is for **Windows**. On a Mac, 1.6.1 stays current and keeps working as it does today; 2.0 for
macOS will follow.

---

## ⚡ A native app

- Rewritten in Rust, with no browser engine bundled behind the window.
- Opens faster, and runs as one process instead of six, using much less memory.
- A much smaller download: about 9 MB instead of about 100 MB.
- Updates are signed: 2.0 only installs releases signed by this project.

## 🗂️ A clearer profile list

- Each profile reads as one line: its name, then the account and role.
- Folders are grouped into their own panels.
- Only Identity Center profiles carry a tag; SAML, the usual case, needs none.
- Uses the Windows system font, as 1.x did.

## 🔄 Updates you can see

- When an update has downloaded, a green download button appears in the title bar: click it to
  restart into the new version.
- If a download fails, a red warning button takes its place. Hover over it for the reason, or click
  it to try again.

## ▶️ Resume auto refresh from the Profiles page

- When auto refresh is paused, the banner on the Profiles page now has a **Resume auto refresh**
  button. You no longer need to go to Settings.

## ↔️ Resizable Terminal panes

- Drag the edges between the command explorer, the terminal, the AI assistant and the command
  details to resize them.
- The side panes keep their proportions when you resize the window, and the terminal always keeps
  enough room.
- Your layout is remembered between launches. Sizes you set in 1.x start fresh once.

## 🧭 Setup wizard

- A mistyped IdP password can be corrected: *Back* returns to the sign-in step, and the import step
  offers the sign-in fields again when the saved password fails.
- Roles load on their own once the IdP URL and a sign-in are known, with a clear "signing in"
  indicator while they load.

## 🖼️ App icon

- The icon in the title bar, on the sign-in screen and on the splash is drawn sharply at any display
  scale.
- Picking a new icon updates the taskbar button straight away.

---

**Going back:** if you need 1.x again, install 1.6.1 from the releases page. Your profiles, folders,
settings and saved sign-ins are kept either way.
