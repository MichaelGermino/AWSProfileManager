# v2.0.0-beta.1 — the native rewrite (beta)

**This is a test build of AWS Profile Manager 2.0.** You are seeing it because *Allow pre-release*
is turned on in Settings. If you would rather stay on the stable version, reinstall 1.6.1 from the
releases page: your profiles, folders, settings and saved sign-ins are kept either way.

---

## ⚡ Rebuilt as a native app

- Rewritten in Rust: no more bundled browser engine behind the window.
- Opens faster and uses about a third of the memory of 1.6.1.
- A much smaller download (about 9 MB instead of about 100 MB).

## 🗂️ A clearer profile list

- Each profile reads as one line: name, then account and role.
- Folders are grouped panels, and only Identity Center profiles carry a tag.
- Uses the Windows system font, as 1.x did.

## 🧭 Setup wizard fixes

- A mistyped IdP password can now be corrected: *Back* returns to the sign-in step, and the import
  step offers the sign-in fields again when the saved password fails.
- Roles load on their own when the IdP URL and a saved sign-in are already known.

## 🔄 Updates

- Updates now come from 2.0's own updater, which only installs releases signed by this project.
- Your data stays where it was: upgrading never rewrites or deletes your 1.x files.
