# v2.0.0-beta.2 — native rewrite (beta)

**This is a test build of AWS Profile Manager 2.0.** You are seeing it because *Allow pre-release*
is turned on in Settings. If you would rather stay on the stable version, reinstall 1.6.1 from the
releases page: your profiles, folders, settings and saved sign-ins are kept either way.

---

## 🔄 2.0 updating itself

- This release exists to test 2.0's own updater: a beta.1 install should find it, check its
  signature, and install it without going through the 1.x updater.

## 🛡️ Dependencies

- `url` and `cookie` updated to patched versions for newly published security advisories.
