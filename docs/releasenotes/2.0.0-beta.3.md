# v2.0.0-beta.3 — native rewrite (beta)

**This is a test build of AWS Profile Manager 2.0.** You are seeing it because *Allow pre-release*
is turned on in Settings. If you would rather stay on the stable version, reinstall 1.6.1 from the
releases page: your profiles, folders, settings and saved sign-ins are kept either way.

---

## 🔄 Updates you can see

- When an update has downloaded, a green download button appears in the title bar, as in 1.x:
  click it to restart into the new version. Until now the only way to install was from Settings.
- If a download fails, a red warning button takes its place: hover for the reason, click to retry.

## ✨ A sharper app icon

- The app icon in the title bar, on the sign-in screen and on the splash is now scaled properly
  for its size and your display, instead of looking soft and jagged.
